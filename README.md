# King Regal · demo de rediseño

Propuesta de rediseño de [kingregal.com](https://www.kingregal.com/) con una intro 3D hecha con golosinas (Three.js).

- `index.html`: web completa con intro corta; las golosinas forman la corona al hacer scroll.
- `story.html`: versión larga por capítulos.

Sin build ni dependencias. En local: `python -m http.server 8933`.

Demo conceptual no oficial, con `noindex`. Fotos, textos y marca son de King Regal y se cargan desde su web.
